# Super Admin Control Centers — User Guide

## Access

Super Admin only. Navigate via **Admin Sidebar → Platform** section.

## Control Centers

### Platform Configuration
Central hub for verification, featured, sponsored, auction, flash sale, and vendor subscription pricing. All changes are versioned and audited.

### Commission Center
- **Platform Commission** — per-category percentage, fixed/min/max fees, enable/disable
- **Category Rules** — priority and sync status with commission rule engine
- **History** — vendor, product, order, commission, status, date
- **Analytics** — revenue, top categories/vendors, monthly trend

Changes apply to **future orders** after save.

### Referral Center
Configure payout limits, cookie duration, category referral rates, manage codes (enable/disable/reset/delete), and review fraud signals.

### AI Control Center
App Store-style cards for each AI product: enable/disable, monthly/promotion pricing, credits, trial, usage limits, vendor eligibility.

### Delivery Control Center
Shipping modes (Vendor, Pickup, Yebone Delivery), pricing, zones, courier partners. Yebone Delivery starts OFF with Coming Soon messaging.

### Growth Center
Marketing modules via Growth Commerce panel plus growth feature toggles.

### Commission Rules
Rule engine settings (stacking, min/max, seasonal) plus full commission rules CRUD.

### Coupon Center
Coupon statistics, discount defaults, usage analytics, fraud patterns, expiry list, bulk import validation.

### Banner Management
Create scheduled banners (hero, property, events, flash sale, popup, category, auction) with Cloudinary upload and preview.

### Property & Mobility
Extended admin panel: moderation, verification pricing, reports, agency settings.

## Saving Changes

Use the **sticky save bar** at the bottom when changes are pending. Optional reason field is recorded in the audit log.

## Responsive Use

- **Desktop** — fixed sidebar, multi-column grids
- **Tablet** — collapsible sidebar, 2-column layout
- **Mobile** — single column, touch-friendly controls, sticky save bar
